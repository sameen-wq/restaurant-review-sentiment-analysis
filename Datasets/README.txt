# Dataset

For this project, I used the Yelp restaurant review dataset from the UCI Machine Learning Repository. It contains 1,000 restaurant reviews, with 500 positive reviews (1) and 500 negative reviews (0).

After removing duplicate reviews, I used 996 reviews for my sentiment analysis project.

The dataset file is named `yelp_labelled.txt`. My Jupyter notebook downloads this file automatically. If the download does not work, the dataset can also be downloaded manually from UCI and placed in the `data` folder.

## Dataset Source

- **Dataset:** Sentiment Labelled Sentences
- **Author:** Dimitrios Kotzias (2015)
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences)
- **DOI:** https://doi.org/10.24432/C57604
- **License:** Creative Commons Attribution 4.0 (CC BY 4.0)

## Reference

Kotzias, D., Denil, M., de Freitas, N., & Smyth, P. (2015). *From Group to Individual Labels Using Deep Features*. KDD.

## Note

This project was inspired by the restaurant review sentiment analysis exercise from my Udemy NLP coursework. However, I used the Yelp dataset from UCI instead of the original `Restaurant_Reviews.tsv` file provided in the course.
